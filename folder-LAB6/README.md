#  Walmart Sales Prediction

## Overview
This project predicts weekly Walmart sales using Linear Regression based on economic and seasonal features.

## EDA
- Explored data using pairplots and heatmaps  
- Sales distribution is right-skewed  
- Identified moderate correlations between features  

## Feature Engineering
- Converted Date to datetime  
- Extracted Month and Year to capture seasonal patterns  

##  Model
- Linear Regression  
- Train/Test split (70/30)  

##  Evaluation
- Used MAE and MSE  
- Model captures general trends but affected by outliers and seasonality  

## Conclusion
Linear Regression provides a solid baseline, with potential improvement using more advanced models.
