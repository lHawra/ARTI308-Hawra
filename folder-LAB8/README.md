# Lab 8 - K-Nearest Neighbors (KNN)

## Overview
This lab applies the K-Nearest Neighbors (KNN) algorithm to classify data based on similarity between data points.

## Dataset
- KNN_Project_Data

## Steps
- Data exploration and visualization (pairplot)
- Feature standardization using StandardScaler
- Train/test split
- Model training using KNN
- Evaluation using confusion matrix and classification report
- Choosing the optimal K value (elbow method)
- Retraining the model with the best K

## Conclusion
The KNN model was implemented and evaluated successfully. Standardizing the data improved performance, and selecting an appropriate K value using the elbow method resulted in better classification accuracy.
