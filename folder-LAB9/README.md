# Lab 9 - Random Forest & Decision Trees

## Overview
This lab applies Decision Tree and Random Forest algorithms to classify loan data and compare their performance.

## Dataset
- loan_data.csv

## Steps
- Data exploration and visualization (EDA)
- Feature engineering (handling categorical data using get_dummies)
- Train/test split
- Training a Decision Tree model
- Evaluating Decision Tree (confusion matrix & classification report)
- Training a Random Forest model
- Evaluating Random Forest
- Comparing model performance
